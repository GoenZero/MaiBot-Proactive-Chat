# MaiBot-Proactive-Chat

**让 MaiBot 主动找你聊天的轻量插件**

[![License](https://img.shields.io/badge/license-GPL--3.0-green.svg)](LICENSE)
[![MaiBot](https://img.shields.io/badge/MaiBot-1.3.5%2B-blue)](https://github.com/Mai-with-u/MaiBot)

聊天安静了一段时间、到了 AI 自己约好的时间、或者 AI 主动说了话你没回时，插件会提醒 AI 一下：「可以主动找对方聊聊了」。**说不说、说什么，由 AI 自己决定。**

## 设计初衷

**插件只负责「到点叫醒她」，什么时候想起你、提起什么，由她自己决定。**

- **不替 AI 说话**：插件不自己调用模型，也不直接发消息，只用 MaiBot 自带的「主动任务」提醒 AI。AI 会结合人设、记忆和最近的聊天来决定，也可以选择不说。
- **AI 可以自己约时间**：你说明天面试，她可以记一句「明天傍晚问问面试结果」，到点插件就提醒她，并带上这句备注。没聊完的话题也可以这样约到改天接着聊。
- **不打扰**：有免打扰时段和每天次数上限。她主动说了你没回，只再提醒她一次（追问不追问由她决定）；之后在你开口前不再主动。
- **不污染记忆**：提醒只出现在 AI 当前的上下文里，不写进聊天记录数据库，MaiBot 的表达学习和长期记忆都不会收录。提醒写得短而中性，不编造日程、心情或任何「事实」。
- **轻量**：几百行代码，没有额外依赖，不往每次请求里塞大段提示词。

## 怎么工作

| 情况 | 插件做什么 |
|---|---|
| 你们安静了一段时间（带随机浮动） | 提醒她可以主动找你聊聊 |
| 到了她自己约的时间 | 提醒她，并带上她当时写的备注 |
| 她主动说了话，你一段时间没回 | 再提醒她一次，可以追问，也可以不追问 |
| 追问之后你还是没回 | 不再按「安静」提醒，等你开口再重新计时 |
| 免打扰时段 | 不提醒；她约在这段时间的提醒，顺延到免打扰结束 |
| 当天「安静」提醒的次数用完 | 当天不再按「安静」提醒；她自己约的提醒不受影响 |
| 你们正在聊天 | 她约的提醒稍等几分钟，不插话 |

## 安装

把本仓库放到 MaiBot 的 `plugins/` 目录下，重启 MaiBot：

```sh
cd /path/to/MaiBot/plugins
git clone https://github.com/GoenZero/MaiBot-Proactive-Chat.git
```

然后在 WebUI 的插件配置页填上「聊天对象」，**再让对方先发一条消息**：插件要从这条消息认出是哪个聊天。

要求 MaiBot 1.3.5 及以上（插件 SDK 2.10 及以上）。已在 MaiBot 1.3.9 上验证。

## 配置

都可以在 WebUI 的插件配置页随时调整，改了立即生效。

| 分组 | 设置 | 默认 | 说明 |
|---|---|---|---|
| 聊天对象 | 平台 | imessage | 对方所在的平台 |
| 聊天对象 | 对方账号 | （空） | iMessage 填手机号，带国家代码。只对和这个人的私聊生效 |
| 主动频率 | 安静多久后可以主动 | 5 小时 | 滑块，0.5–24 小时 |
| 主动频率 | 随机浮动 | 30% | 滑块，0–50%。30% 表示 5 小时会落在 3.5–6.5 小时之间 |
| 主动频率 | 每天最多主动几次 | 2 | 滑块，0–20。只算「安静太久」的提醒，她自己约的提醒和追问不算 |
| 主动频率 | 没回复多久后追问 | 30 分钟 | 填 0 表示不追问 |
| 免打扰 | 开始 / 结束 | 00:00 / 09:00 | 按 MaiBot 所在系统的时间算，可以跨午夜（例如 23:00 到 08:00） |
| AI 自己约时间 | 允许 | 开 | 关掉后 AI 看不到约时间的工具 |
| AI 自己约时间 | 最早多久以后 | 10 分钟 | |
| AI 自己约时间 | 最晚多少天以内 | 7 天 | 滑块，1–30 |
| AI 自己约时间 | 同时最多几个约定 | 3 | 滑块，1–10 |

> 免打扰按 MaiBot 所在系统的时间算。在 Docker 里运行时，容器的时区可能和你所在地不一样。发 `/proactive_status` 可以看到系统现在几点，先确认一下。

## AI 能用的工具

只在设定对象的私聊里出现，其他聊天里看不到。

| 工具 | 作用 |
|---|---|
| `proactive_schedule` | 约个时间再主动找对方聊。时间可以写「几分钟以后」，也可以写具体时间（`18:00`、`2026-10-20 18:00`），再加一句给自己的备注 |
| `proactive_cancel` | 取消一个约定，例如对方已经主动提起了那件事 |

## 管理命令

| 命令 | 说明 |
|---|---|
| `/proactive_status` | 查看系统时间、下次提醒、今天提醒了几次、AI 约好的提醒（备注只在设定对象的聊天里显示） |

## 关于记忆

插件用的是 MaiBot 自带的主动任务（`maisaka.proactive.trigger`）。根据 MaiBot 1.3.9 的源码：

- 提醒会作为一条系统提醒放进 AI 当前的上下文，不写进聊天记录数据库；长期记忆是从数据库里的聊天记录生成的，所以不会收录。
- 表达学习、黑话学习只学双方真正说过的话，也不会学到提醒。
- 聊天很长时，MaiBot 会把旧消息概括成「聊天回想」，这时提醒有可能被一起概括进去。所以提醒写得短而中性，不包含任何虚构的信息。
- AI 最后真正说出口的话会正常进入记忆。这是她自己说的话，本来就该记住。

## 已知限制

- 只支持一对一私聊。
- 安装或更换聊天对象后，要等对方先发一条消息，插件才能开始工作。
- AI 收到提醒后在 10 分钟内开口，才算「她主动说了话」（之后才会有追问）。
